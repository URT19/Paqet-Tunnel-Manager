## Quick Start

Run the script on **both servers** as **root**:

#### Online

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/URT19/Paqet-Tunnel-Manager/refs/heads/main/paqet-manager.sh)
```


#### Offline


```
curl -fsSL -o paqet-manager.sh https://raw.githubusercontent.com/URT19/Paqet-Tunnel-Manager/refs/heads/main/paqet-manager.sh
```

```

chmod +x paqet-manager.sh
sudo ./paqet-manager.sh

```
